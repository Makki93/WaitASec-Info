# WaitASec Info

Public website, privacy information and support for WaitASec.

- Website: https://makki93.github.io/WaitASec-Info/
- Privacy (German): https://makki93.github.io/WaitASec-Info/privacy/
- Privacy (English): https://makki93.github.io/WaitASec-Info/privacy/en/

The application repository remains private. This repository contains only public website files.

## Publish

GitHub Pages publishes the root directory of `main`. `.nojekyll` keeps this a plain static site. HTTPS is enforced. No build dependencies, scripts, external fonts or analytics are needed.

Edit the HTML/CSS, inspect the rendered pages, commit named files and push `main`. Keep German and English privacy content aligned with the shipped beta. Never add private account data, Screen Time tokens or signing files.

Support issues are public. Do not include personal information or private screenshots.
